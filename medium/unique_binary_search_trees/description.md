# Unique Binary Search Tree

Given an integer `n`, return _the number of structurally unique **BST'**s (binary search trees) which has exactly `n` nodes of unique values from `1` to `n`_.

##### Example 1:

![example1](./example1.jpg)

> **Input**: n = 3
>
> **Output**: 5

##### Example 2:

> **Input**: n = 1
>
> **Output**: 1

##### Constraints:

- `1 <= n <= 19`
